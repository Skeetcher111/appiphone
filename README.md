# MCP iPhone

Возвращаем купленные и бесплатные приложения обратно на iPhone под твоим собственным Apple ID, с оригинальной подписью Apple, без джейлбрейка и без ресайна.

Раньше продукт назывался AppIPhone.

## Проблема

Разработчик снял приложение с продажи или его удалили из российского App Store, а оно у тебя уже было куплено или установлено раньше. Обычный App Store такое приложение больше не покажет и не поставит, даже если оно всё ещё привязано к твоему Apple ID.

## Что делает MCP iPhone

Устанавливает на iPhone приложения, доступные твоему Apple ID, включая снятые с продажи, через официальный механизм Apple, а не джейлбрейк и не пересборку .ipa из левых источников. Пароль Apple ID используется один раз для входа через защищённое соединение и нигде не сохраняется. Первая установка бесплатна, дальше разовая оплата за установку без подписки.

## Как это работает

Скачиваешь клиент для Windows. Входишь под своим Apple ID и подтверждаешь вход кодом на iPhone. Подключаешь iPhone по USB. Выбираешь приложение из списка доступных — готово.
