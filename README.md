# AppIPhone

Возвращаем купленные и бесплатные приложения обратно на iPhone под твоим собственным Apple ID, с оригинальной подписью Apple, без джейлбрейка и без ресайна.

## Проблема

Разработчик снял приложение с продажи или удалил его из App Store, а оно у тебя уже было куплено или установлено раньше. Обычный App Store такое приложение больше не покажет и не поставит, даже если оно всё ещё привязано к твоему Apple ID.

## Что делает AppIPhone

Устанавливает на iPhone приложения, доступные твоему Apple ID, включая снятые с продажи, через официальный механизм Apple, а не джейлбрейк и не пересборку .ipa из левых источников. Apple ID не хранится на сервере, авторизация происходит локально на твоём компьютере. Первая установка бесплатна, дальше разовая оплата за установку без подписки.

## Как это работает

Скачиваешь клиент для Windows. Входишь под своим Apple ID локально, ничего никуда не отправляется. Подключаешь iPhone по USB. Выбираешь приложение из списка доступных — готово.

## Доказательство: Apple ID не уходит на сервер

В `src/` лежат два реальных файла из рабочего приложения — не витрина, настоящий код:

- [`src/accounts.js`](src/accounts.js) — вся логика входа в Apple ID. Пароль и код 2FA передаются только локальному `ipatool` на компьютере пользователя; на сервер AppIPhone они не отправляются ни в каком виде.
- [`src/preload.js`](src/preload.js) — полный список команд, которыми интерфейс приложения обращается к его внутренней части (Electron IPC). Учётные данные Apple ID в нём не пересылаются наружу.

## О репозитории

Это витрина проекта, а не полный исходный код: движок установки, работа с устройством и вся логика лицензий закрыты (AppIPhone — коммерческий продукт). Опубликованы только два файла выше — как открытое доказательство того, что данные Apple ID не покидают компьютер пользователя.
